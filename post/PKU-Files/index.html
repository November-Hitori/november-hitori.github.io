PKU 我上过的课程文件留档及评价

PKU 相关 · 2026-08-10 · 9 分钟阅读
PKU

大一上（2025 秋）

线性代数 (B)

  • 老师：向圣权；
  • 教材：《简明线性代数》丘维声，北京大学出版社，第一版；
  • 考核：平时分 + 期中 + 期末

老师很好，但是书很烂。

  • 我的产出：十八次作业。
  • 学习经验：感觉就应该多看看丘砖（《高等代数学习指导书》丘维声），这书不错。
  • 得分：89.5

高等数学 A（一）

  • 老师：吴金彪；
  • 教材：《高等数学（上册）》李忠，周建莹，北京大学出版社，第三版；
  • 考核：平时分 + 期中 + 期末

老师略有点 book reader，但是高数应该是看自学的，我比较摆子于是分比较低。

  • 我的产出：十次作业
  • 经验：不能太打摆，使用 xyt 讲义 和 ztf 讲义 就可以得到一点好的成绩的，呜呜。
  • 得分：80

力学

  • 老师：刘树新；
  • 教材：《力学》刘树新，北京大学出版社，第一版；
  • 考核：平时分 + 期中 + 期末 + 加分题（可选）

第一个学期学的最差的一门课/ll，我确实听不懂这个抱歉呜呜，老师很有趣，但是我确实听不明白。

  • 我的产出：十一次作业
  • 得分：77

普通物理实验（1）

  • 老师：拼盘课，每个老师负责一个 / 一些实验。
  • 教材：《新编基础物理实验》吕斯骅，段家忯，张朝晖，高等教育出版社，第二版。
  • 考核：每个实验的预习报告，实验表现，实验报告总和。

很难评价的课程，可以说任务量很大，而且由于下调到大一，预习报告的难度很高，内容很多很杂。

  • 我的产出（实验报告）：
    • 霍尔效应测量磁场
    • 直流电桥测量电阻 + 非平衡电桥测量铂电阻的温度系数
    • 迈克耳孙干涉仪
    • 测定介质中的声速
    • 测定金属的杨氏模量
  • 得分：86

英美短篇小说文本分析与鉴赏

  • 老师：茆卫彤。
  • 教材：老师自己选的若干篇英美短篇小说。
  • 考核：平时分 + pre 及论文 + 期末。

英美短篇小说还是很充分有趣的内容，虽然老师可能略有点 ppt reader，上课还是听得很懂的，但是我英语比较差哎哎，所以最后得分并不好看。

  • 我的产出：
    • 与其他两位同学完成的 PPT
    • 小论文
  • 得分：81

思想道德与法治

  • 老师：拼盘课，金德楠主管。
  • 教材：应该是有一本的，不过我没看过。
  • 考核：平时分 + pre + 论文 + 期末

我不听政治课。做 pre 的时候八个人集体宣布不认真搞敷衍敷衍（。
由于涉及政治相关，我不会公开我写的答辩（

  • 得分：89

新时代劳动理论 / 新时代劳动者十讲

  • 慕课。
  • 合格制，60 分即可。

在扩展商店中下载 Global Speed 即可纯享 16 倍速播放，这样就能刷完了。

计算概论A

  • 老师：王厚峰
  • 编程网格提交作业。
  • 考核：计算机基础知识小测 + 平时作业 + 期中 + 期末 + 大作业

给分很诡异的课程，大作业显著超出大一学生能力，作业量又大，网站又烂。

  • 产出：Sleepwalk
  • 得分：92，应该是乱做小测导致的。

军事理论

  • 拼盘课。
  • 考核：平时分 + 期末

背书即可的课程。

  • 得分：89

思想政治实践（上）

  • 爱乐传习
  • 考核：一篇心得。

后勤组。由于我写的实在答辩，我不会公开我写的答辩。

大一下（2026 年春）

中国近现代史纲要

  • 老师：赵诺。
  • 考核：平时+期中读书报告/pre+小论文+考试

好像这节课要倒闭了，呜呜。
赵诺老师实在是非常有趣的老师，讲课很有趣味度的！
考试只需背诵，或者不背开始口胡。

  • 得分：86
  • 鉴于这是一门思政课，我不会公开我写的答辩（

太空探索

  • 老师：傅绥燕，谢伦，周煦之
  • 考核：平时+两次作业+一次小测+期末（可带 cheatpaper）

一般通识课，主要涵盖了太空相关的知识。
由于我 P/F 了，所以我不会评价一些事情。

  • 我的产出：
    • 关于抵御太阳风暴的报告
    • 木卫二深海感应磁场与冰壳内部结构精细探测任务
  • 得分：P

普通物理实验（2）

  • 老师：拼盘课，每个老师负责一个 / 一些实验。
  • 教材：《新编基础物理实验》吕斯骅，段家忯，张朝晖，高等教育出版社，第二版。
  • 考核：每个实验的预习报告，实验表现，实验报告总和。

本学期莫名其妙的引入了开放实验，本人极其诋毁这一行为，实在是 /tuu。
问题一如既往的大，神秘的实验仪器、超前的实验预习、总之，我很诋毁这门课程。

  • 我的产出：实验报告。
  • 得分：85。

热学

  • 老师：全海涛。
  • 教材：《普通物理学教程 热学》秦允豪，高等教育出版社，第四版。
  • 考核：作业+期中+期末

我学不明白热学呜呜。但是老师确实挺好期中开根号乘十了，期末发挥得中规中矩吧，所以就拿个一般分数。不七开头就算成功！！！1

  • 得分：80

电磁学

  • 老师：何琼毅。
  • 教材：《大学物理通用教程 电磁学》陈秉乾、王稼军，北京大学出版社，第二版
  • 考核：作业+期中+期末

何琼毅老师的讲课水平很不错，实际上电磁学是我听得最明白的学科，期中考得还不错，期末老师加大了试题难度，拿个一般分数中规中矩就算成功！！！1

  • 得分：91

线性代数A (II)

  • 老师：高峡。
  • 教材：《高等代数 下册》丘维声，高等教育出版社，第三版
  • 考核：作业+期中+期末

高峡老师的讲课是有独一套的方法的，实际上如果能听进去对线代的理解是很到位的，缺点是会掺杂一些很超标的东西，以及他出分真的很慢。
推荐阅读：《高等代数学习指导书 下册》丘维声，清华大学出版社，第二版。

  • 得分：97

羽毛球

  • 老师：欧阳泽蔓
  • 考核：理论+单打+双打+发球+高远+体测

非常好的一门课！！！！！！
感谢 lmy 大哥带我飞！！！！

  • 得分：89

高等数学A（二）

  • 老师：周蜀林
  • 教材：《高等数学（下册）》李忠，周建莹，北京大学出版社，第三版；
  • 考核：作业+期中+期末

周蜀林第一年教高数 A，实在不赖，我必须承认他对于一些点提出的理解角度是很好的，很有利的。
以及助教大哥不赖，感恩 crc。

  • 得分：93
