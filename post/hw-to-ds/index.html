T4

enQueue(x) {
	push(S2,x);
}
deQueue(x) {
	if(isEmpty(S1)) while(!isEmpty(S2)) push(S1,pop(S2));
	return pop(S1);
}
  • S2S_2S2​ 存储入队的元素，作为一个缓冲区，因为为了实现先进先出，不得不在 S1S_1S1​ 中倒着入栈元素，当需要出队时，将 S2S_2S2​ 中的元素清空，全部按顺序加入 S1S_1S1​ 中，这样其实实现了将当前入队的元素倒着加入 S1S_1S1​，这样就满足了先进先出。
  • 单次 enQueue 最坏 O(1)O(1)O(1)，单次 deQueue 最坏 O(n)O(n)O(n)，均摊下来单次操作复杂度是 O(1)O(1)O(1)。
